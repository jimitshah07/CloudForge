\# CloudForge — Secure AWS Infrastructure \& Application Delivery Platform



\## About

CloudForge is a hands-on portfolio project that grows from Git fundamentals into a secure, automated AWS cloud platform.



\## Goals

\- Learn Git and GitHub workflows.

\- Build a foundation in Linux and cloud networking.

\- Provision AWS infrastructure using Terraform.

\- Learn GitLab CI/CD, Docker, and Kubernetes.

\- Apply cloud security best practices.



\## Current Stage

\*\*Stage 1: Git Foundation\*\*



Currently practising repositories, commits, branches, merging, remotes, fetching, and pushing.



\## Project Structure

\- `apps/` — application files.

\- `docs/` — project notes and documentation.

\- `.gitignore` — files and directories Git should ignore.



\## Learning Approach

Build the platform incrementally, understand each tool, and document the practical work as the project evolves.
CloudForge is maintained as a continuous hands-on learning project.
